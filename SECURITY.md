# Security Policy

HackRadar treats secrets and production data carefully.

## Reporting a vulnerability

If you believe you found a security issue, do not publish it in a public issue or pull request. Instead:

- Open a private report if the platform supports it, or
- Contact the maintainers through the repository's private channels if available

Include:

- A short summary
- The affected area
- Steps to reproduce if safe to share
- Any proof of concept or exploit details privately
- Your contact information if you want follow-up

## What not to share publicly

- API keys
- SMTP credentials
- Database URLs
- `.env` contents
- Production-only data
- Exploit steps that could help an attacker

## Expectations

We will investigate reports in good faith. This project does not promise a formal SLA, but we do try to respond promptly and responsibly.
