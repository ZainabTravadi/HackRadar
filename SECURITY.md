# Security Policy

If you discover a security vulnerability, please do not disclose it publicly. Open a private issue or contact the project maintainers via the repository and include:

- A short summary of the issue
- Steps to reproduce (if applicable)
- Any PoC or exploit code (privately)
- Your contact information if you are willing to communicate

Do not include sensitive production data or credentials in reports. The project will triage and respond; no specific SLA is promised at this stage.
