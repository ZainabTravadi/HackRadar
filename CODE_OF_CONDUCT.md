# Code of Conduct

HackRadar is a community project. We want contributors to feel welcome, respected, and safe.

## Expected behavior

- Be respectful and inclusive.
- Keep feedback focused on code, design, documentation, and process.
- Assume good intent when possible.
- Help newcomers learn the project.

## Unacceptable behavior

- Harassment
- Hate speech
- Personal attacks
- Doxxing
- Trolling
- Repeatedly ignoring project rules

## How to raise a concern

If you experience or witness behavior that makes participation uncomfortable, open a GitHub issue or follow the security guidance in `SECURITY.md` if the concern is sensitive.

Please do not post exploit details or private credentials in public issues.
