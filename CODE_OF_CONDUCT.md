# Code of Conduct

HackRadar is an open, community-driven project. All participants are expected to be respectful and constructive.

- Be respectful and inclusive.
- No harassment, hate speech, or abusive language.
- Focus feedback on code and behavior, not people.
- Be helpful and patient with newcomers.

If you experience or witness unacceptable behavior, please open a GitHub issue or contact the maintainers via the repository. Do not post exploitative or security-sensitive details in public issues; see SECURITY.md for guidance.
